# 02 — v0.1 Scope

## v0.1 must include

| Area | Include in v0.1 |
|---|---|
| Account | Register/login, Google login |
| Map | Search, pan, click location |
| Kingdom creation | Valid land check, 50,000 m² land credit, starter buildings, starter units |
| Land | Districts, land buying packages, prices, cooldowns |
| Economy | 10-minute tick income, food consumption, population |
| Buildings | Build/upgrade with 1 construction slot |
| Army | Train units with 1 training queue |
| Movement | Distance-based army travel |
| Combat | Basic attack/defense formula |
| Scouting | Approximate scout reports |
| Reports | Battle, scout, land purchase, construction reports |
| Rankings | Total land, military power, economy score, knowledge score |
| Admin | View users/kingdoms/reports, run test ticks |

## Delayed until after v0.1

| Feature | Reason |
|---|---|
| WebSockets/realtime | Polling is enough first |
| Full chat | Moderation burden |
| Area-type bonuses | Balance later |
| Wood/Stone/Iron | Avoid early economy bloat |
| Advanced diplomacy | Keep alliance system simple |
| Payments/premium | Prove game loop first |
| Mobile app | Web first |
| Manual building placement | District system is enough |
| Advanced battle tactics | Basic formula first |

## v0.1 release definition

v0.1 is releasable when a player can:

1. Register/login.
2. Create a kingdom on a map-selected valid location.
3. Start with the locked land, resources, population, buildings, districts, and units.
4. Watch resources update through ticks.
5. Build/upgrade buildings.
6. Train units.
7. Buy land packages with cooldowns.
8. Scout and attack valid enemy kingdoms.
9. Receive battle/scout/construction/land reports.
10. Join or create a simple alliance.
11. Compete on leaderboards.
