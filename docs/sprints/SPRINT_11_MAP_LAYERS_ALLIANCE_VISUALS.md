# Sprint 11 — Strategic Map Layers + Alliance Visuals

## Goal

> Make the real-world map useful for strategic reading.

## Scope

- Add map layer toggles
- Add kingdom border layer
- Add alliance color layer
- Add war zone layer
- Add protected kingdom layer
- Add wild area layer
- Persist player map preferences

## Out of scope

- Do not redesign v0.1 systems.
- Do not add v0.3 features.
- Do not introduce payments or full chat.

## Acceptance criteria

- Player can toggle map layers
- Alliance colors are visible where applicable
- Protected kingdoms are distinguishable
- Wild areas are visible when enabled
- Map preferences persist
- Map remains usable on normal dashboard devices
