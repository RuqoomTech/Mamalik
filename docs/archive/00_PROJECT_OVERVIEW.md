# 00 — Project Overview

## Name

**Mamalik / ممالك**

## Core identity

Mamalik is a browser-based, tick-based grand strategy MMO played on a real-world map. The game is inspired by the feeling of older tick-based MMO strategy games, but it is an original project with its own rules, identity, UI, code, economy, map model, and systems.

## Core fantasy

A player chooses a valid location on the real-world map and founds a virtual kingdom in their name. That kingdom starts with 50,000 m² of usable land credit. The player grows through economy, buildings, districts, technology, armies, alliances, scouting, conquest, and leaderboard competition.

## Core loop

1. Create or manage a kingdom.
2. Receive resources every 10-minute tick.
3. Spend resources on buildings, upgrades, land, units, and research.
4. Allocate usable land between districts.
5. Train armies and scouts.
6. Scout enemies for approximate information.
7. Attack or defend using distance-based army movement.
8. Gain limited land from defeated enemies.
9. Compete on persistent leaderboards.

## World model

Mamalik is an endless persistent MMO world. There is no season reset and no final victory condition. Progression is based on leaderboards.

## v0.1 philosophy

v0.1 should prove the playable core, not the final dream. It must include enough systems to feel like a real strategy MMO while delaying high-risk features such as full chat, WebSockets, payments, advanced diplomacy, advanced battle tactics, and mobile apps.
