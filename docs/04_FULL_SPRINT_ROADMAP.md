# 04 — Full v0.1 Sprint Roadmap

## Why this file exists

The v0.1 scope must be split into all required sprints, not only Sprint 1. Each sprint below has a goal, scope, deliverables, and acceptance criteria in its own file.

## Sprint overview

| Sprint | Name | Main outcome |
|---|---|---|
| Sprint 1 | Foundation + Kingdom Creation | A logged-in player can create a kingdom and see a dashboard |
| Sprint 2 | Tick Engine + Economy Loop | The world updates every 10-minute tick |
| Sprint 3 | Land Buying + District Management | Players can buy land and reassign unused district land |
| Sprint 4 | Real Map Validation + Borders | Location validation and border generation become real enough for v0.1 |
| Sprint 5 | Movement + Scouting + Combat | Players can scout and attack valid targets |
| Sprint 6 | Alliances + Reports + Rankings + Admin Polish | The social/competitive layer is ready for v0.1 testing |

## Release dependency flow

```text
Sprint 1: foundation and kingdom creation
  ↓
Sprint 2: tick engine makes kingdoms live
  ↓
Sprint 3: land and district growth
  ↓
Sprint 4: better real-world map validation
  ↓
Sprint 5: military interaction
  ↓
Sprint 6: alliance/social/ranking/admin polish
  ↓
v0.1 playable test release
```
