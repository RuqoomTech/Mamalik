# Mamalik v0.2 Scope — World Depth Update

## Purpose

Mamalik v0.1 proves the core playable MMO loop. Mamalik v0.2 deepens the world without replacing the v0.1 foundation.

v0.2 should answer:

> Does the world feel alive, strategic, and worth exploring every day?

## v0.2 product theme

**World Depth Update**

The focus is not more raw complexity. The focus is making the real-world map, scouting, progression, alliances, and onboarding more meaningful.

## v0.2 must-have features

| Area | Include in v0.2 |
|---|---|
| Area bonuses | Location area type affects economy/growth/land strategy |
| NPC / wild areas | Scoutable and attackable non-player targets for early activity |
| Tech tree | Expanded Knowledge-based upgrades |
| Scouting | More useful report tiers and counter-intelligence signals |
| Map layers | Toggle useful strategic views on the real-world map |
| Alliance communication | Simple announcements and pinned alliance messages |
| Onboarding | Quest/tutorial missions for new players |
| Notifications | Realtime-style notifications for important events only |

## Explicitly not in v0.2

| Feature | Reason to delay |
|---|---|
| Full open chat | Moderation and abuse risk |
| Payments / premium | Prove retention and balance first |
| Mobile app | Web game must stabilize first |
| Advanced battle tactics | Needs more combat telemetry first |
| Full player trade market | Economy abuse risk |
| Vassals / treaties / tribute | Diplomacy complexity |
| Heroes / generals | Requires deeper combat balance |
| Wood / Stone / Iron | Avoid resource bloat until core economy is stable |
| Manual building placement | District system remains the design |

## Compatibility with v0.1

v0.2 must not break these v0.1 pillars:

- 10-minute tick system
- Persistent endless world
- Real-world map
- 50,000 m² starting usable land credit
- Land credit separate from visible border
- District system instead of manual placement
- Basic combat formula as foundation
- Simple alliances
- Leaderboard-based progression

## v0.2 success criteria

v0.2 is successful when:

- Choosing a real-world location feels strategically different.
- New players have guided missions and activity during protection.
- NPC/wild areas create safe early targets and resource opportunities.
- Knowledge has a stronger purpose through expanded technology.
- Scouts and map layers make strategy clearer.
- Alliances can coordinate lightly without full chat.
- Important events can notify players without making the whole game realtime.
