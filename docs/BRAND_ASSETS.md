Asset type: game logo mark for browser strategy MMO UI, square app logo

Subject: a stylized crown above a simplified globe/map grid with a visible territory border polygon, suggesting kingdoms, land, strategy, and global map control.
Style/medium: vector-friendly premium game emblem rendered as a clean raster logo, crisp edges, simple enough to work at small sizes.
Composition/framing: centered square emblem with generous padding, balanced silhouette, no background scene.

Text: no text, no letters, no numbers.
Constraints: original design only; do not imitate any existing game logo; no flags, no real country borders, no watermark; avoid tiny details that disappear at favicon size.
