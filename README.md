## Project summary

Mamalik is an original browser-based, tick-based grand strategy MMO on a real-world map. Players found a virtual kingdom on valid real-world land, start with 50,000 m² of usable land credit, build districts, grow an economy, train armies, form alliances, scout, fight, and compete on persistent leaderboards.
